# Fixed-Wing Aircraft Project

> 고정익 비행체의 **기체 설계, 비행 제어 및 자율비행 시뮬레이션**을 통합하는 임베디드 프로젝트입니다.

## 프로젝트 소개

본 프로젝트는 고정익 비행체의 구조와 비행 원리를 이해하고, 이를 실제 기체와 제어 시스템으로 구현하는 것을 목표로 합니다. 동체와 날개를 직접 모델링하여 제작하고, 비행체의 자세와 이동을 조절하는 제어 프로그램을 개발합니다.

또한 작성한 제어 알고리즘을 시뮬레이션 환경에서 먼저 검증한 뒤, 그 결과를 바탕으로 기체 설계와 프로그램을 개선합니다.

## 프로젝트 목표

- 고정익 비행체의 동체와 날개 구조 설계
- 3D 프린팅을 이용한 기체 제작
- 조종면을 이용한 비행 제어 시스템 구현
- 자율비행 알고리즘 작성
- 시뮬레이션을 통한 제어 안정성 검증
- 기체 설계와 제어 프로그램의 통합
